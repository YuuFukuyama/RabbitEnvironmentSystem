# 家庭内のウサギ飼育環境温度監視システム

## 概要

家庭で飼育しているウサギの飼育環境を対象とした、温度・湿度監視システムを開発する。

本プロジェクトでは、組み込みソフトウェア開発の実践を目的として、要求定義から設計、実装、テスト、運用、改善までの開発工程を一通り実施する。

---

## 目的

飼育環境の温度・湿度を定期的に測定し、現在の環境状態を確認できるようにする。

また、異常を検知した場合に通知できる仕組みを構築する。

---

## システム構成

```text
┌─────────────────┐
│  温湿度センサー   │
│  AHT20 / SHT31   │
└────────┬────────┘
         │ I2C
         ▼
┌─────────────────┐
│      STM32      │
│    メイン制御    │
└───────┬───┬─────┘
        │   │
     I2C│   │UART
        │   │
        ▼   ▼
   ┌──────┐ ┌────────┐
   │ LCD  │ │ ESP32  │
   └──────┘ └───┬────┘
                │ Wi-Fi
                ▼
          ┌──────────┐
          │ネットワーク│
          └──────────┘
```

## 開発環境

### ハードウェア

* STM32 STBee Mini Ver.2
* I2C LCD
* 温湿度センサー
* ESP32

### 通信

| 通信方式  | 接続先             | 用途       |
| ----- | --------------- | -------- |
| I2C   | STM32 ↔ 温湿度センサー | 温湿度データ取得 |
| I2C   | STM32 ↔ LCD     | 測定値表示    |
| UART  | STM32 ↔ ESP32   | データ送信    |
| Wi-Fi | ESP32 ↔ ネットワーク  | 外部通信     |

---

## 機能

### 温湿度監視

* 温度の定期測定
* 湿度の定期測定
* LCDへの測定値表示
* 異常値の検知

### 通知

* 温度異常の検知
* 湿度異常の検知
* ネットワーク経由での通知

### ネットワーク

* ESP32によるWi-Fi接続
* STM32からESP32への測定データ送信
* 外部からの状態確認
