# 家庭内のウサギ飼育環境温度監視システム

## 概要

家庭で飼育しているウサギの飼育環境を対象とした、温度・湿度監視システムを開発する。



本プロジェクトでは、組み込みソフトウェア開発の実践を目的として、

要求定義から設計、実装、テスト、運用、改善までの開発工程を一通り実施する。

## 目的

飼育環境の温度・湿度を定期的に測定し、現在の環境状態を確認できるようにする。

また、異常を検知した場合に通知できる仕組みを構築する。

## 使用技術

- STM32
- C
- I2C
- UART
- ESP32
- Wi-Fi
- AHT20 / SHT31
- LCD

## 開発環境

### ハードウェア

- STM32 STBee Mini Ver.2
- I2C LCD
- 温湿度センサー
- ESP32

### 通信

- I2C：LCD・温湿度センサー
- UART：STM32・ESP32間通信
- Wi-Fi：ネットワーク通信
